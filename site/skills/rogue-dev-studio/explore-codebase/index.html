About

This skill teaches the agent to explore a codebase efficiently. Use it when you need to understand structure, find patterns, or gather context before changing files.

When to use

  • Understanding unfamiliar module architecture
  • Finding a feature implementation across many folders
  • Preparing a context summary for follow-up work

Principles

  • Parallel over sequential
  • Breadth over depth
  • Structured YAML summaries
  • Explicitly note gaps
