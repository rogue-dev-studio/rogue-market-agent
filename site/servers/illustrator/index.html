Overview

An MCP server that connects Adobe Illustrator to AI agents: read designs, edit objects, export assets, and run pre-press checks.

  • Stable object tracking across tool calls
  • Read, modify, and export Illustrator data
  • Web-standard coordinates (Y-down)
  • Works on macOS and Windows

Category: Design Tools · Tags: MCP, Design, Adobe, Illustrator

About

Illustrator MCP lets agents control desktop Illustrator without repetitive manual scripting. Useful for design-to-web pipelines, export automation, and document QC.

Prerequisites

  • Adobe Illustrator desktop installed (ideally running)
  • Node.js 18+ for npx
  • Agent host with MCP support (Cursor, Claude Code, etc.)

Use cases

  • Extract text, colors, and objects for web handoff
  • Automate SVG / PNG / JPG / PDF exports
  • Run pre-press checks before delivery

Platforms

  • macOS
  • Windows
  • Illustrator CC 2024+

Installation

Add the MCP config below to your agent host, then restart the host.

Cursor MCP config

{ { "mcpServers": { "illustrator": { "command": "npx", "args": ["-y", "illustrator-mcp-server"] } } }

After install

  • Open Adobe Illustrator
  • Confirm the MCP server appears in the host
  • Ask the agent to read or export the active document
